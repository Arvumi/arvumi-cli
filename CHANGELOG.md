# Changelog

## 0.1.2

Initial crates.io release candidate:

- Independently installable `arvumi` executable, without server dependencies.
- GitHub browser sign-in and API-key configuration.
- Deployments from connected Git repositories and streamed build logs.
- Project linking, repository grants, and project creation.
- Environment variables, custom domains, environments, and team management.
- Function resource settings and authenticated PostgreSQL tunnels.
- Package version output, first-use login defaults, and credential-safe config output.
